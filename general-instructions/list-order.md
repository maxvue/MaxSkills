# ORDENAÇÃO DOS ITENS DO ARQUIVO list-skills.yaml
1. **Ordenação de Prioridade no Arquivo:**
   Sempre ordene os itens de cima para baixo, obrigatoriamente, da seguinte forma:
   1º. `AGUARDANDO EXECUÇÃO` (Itens prontos para desenvolvimento ficam no topo absoluto).
   2º. `EXECUTANDO` (Itens em andamento no momento).
   3º. `CONCLUIDA` (Itens finalizados ficam sempre no final do arquivo).
