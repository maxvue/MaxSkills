## PROJETO: SocialMedia (`~/GitHub/SocialMedia`)

**Domínio:** SaaS multi-tenant para **agências de marketing gerenciarem redes sociais de clientes**, com geração de conteúdo assistida por IA. Hierarquia Agency → User → Client → workspace (calendário editorial, temas, notícias, personagens, posicionamento de marca, credenciais, comentários). Núcleo: máquina de estados do evento de calendário (`planned → planning_approved → script_ready → art_ready → scheduled → published`, transição inválida = 422). Funções: planejamento mensal por IA; pipeline de IA por status (copywriting → revisão → direção de arte → geração de arte → análise); publicação automática na Meta (IG/FB) idempotente; notícias RSS com relevância e dedup por LLM; temas com extração multi-formato (texto/url/pdf/áudio/imagem); **personagens com LoRA próprio treinado localmente** (Z-Image/OneTrainer + ComfyUI); captura de avatar por vídeo guiado (MediaRecorder + MediaPipe); custos de IA em USD→BRL; comentários da Meta via webhook.

**Backend:** PHP ^8.3 (8.5 em uso), Laravel ^13.8, **PostgreSQL 18**. Pacotes: laravel/ai ^0.7.1, laravel/horizon, laravel/sanctum (SPA por sessão), laravel/socialite (só Google), spatie/laravel-permission, spatie/pdf-to-text, tightenco/ziggy. Estrutura: Actions, Ai/{Agents,Tools,Support}, Enums (7 de status), Jobs/{Ai,Avatar,Lora,SocialMedia}, Observers, Services/{SocialMedia,Lora}, Helpers. **PKs em ULID**; SoftDeletes em cascata via Observer; índices únicos parciais; global scope `AgencyScope`. 16 controllers de domínio; rotas aninhadas em `/api/clients/{client}/*` sob `auth:sanctum`.

**Frontend:** Vue ^3.6.0-rc.5, TypeScript ^5.9, Vite ^8, vue-router ^5 (SPA, sem Inertia), Pinia ^3 via `@maxvue/max-pinia`, **UnoCSS ^66 (presetMaxUno/wind3/attributify/icons) — sem Tailwind**, Sass, auto-imports, libs Max (`max-components-ui`, `max-pinia`, `max-use`), **@fullcalendar/vue3** (calendário editorial), **@mediapipe/tasks-vision** (Face Landmarker), @vueuse/core, axios, localforage, ziggy-js. Regra dura: todo GET passa por store cacheada MaxPinia.

**Infra:** PostgreSQL 18 (`db:bootstrap`); **Redis + Horizon** com filas `default`, `gemini`, `webhooks` e **`gpu-supervisor`** (filas ollama/lora/lora-train, `balance=false`, 1 processo, para serializar a GPU e evitar OOM de VRAM); `ShouldBeUnique` + backoff na publicação; scheduler (`publish-due`, `fetch-news`). Dev: **proibido `artisan serve`/Octane**; Caddy systemd → PHP-FPM em `https://local.socialmix.com.br`, Vite na 5173, watcher poda `.worktrees` (senão heap OOM do V8). **Serviços externos:** Meta Graph API (publicação IG/FB, comentários, webhook com HMAC `X-Hub-Signature-256`), **Google Gemini via laravel/ai** (2.5-pro, 3.5-flash, 3.5-flash-lite), Google OAuth, **Ollama local** (dedup de notícias, gemma4, num_ctx 80000, gestão de processo), **ComfyUI** (geração com LoRA), **OneTrainer** (treino de LoRA Z-Image em chunks), API de câmbio, RSS. Binários: `pdftotext`, `ffmpeg`/`ffprobe`, `imagick` (dHash perceptual). Sem Docker/CI.

**Testes/qualidade:** Pest 4/PHPUnit 12 (~382 testes, 70 arquivos em Feature/SocialMedia), Vitest 4 (10 specs), `vue-tsc --noEmit`, Pint, smoke commands (`ai:smoke`, `lora:smoke`), Playwright headless só para verificação visual de UI.
