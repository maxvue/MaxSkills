# Projeto: Meu Projeto Teste

Um projeto para demonstrar a sincronização de agentes.

## Regras Gerais

- Use TypeScript sempre que possível.
- Siga os padrões do ESLint do repositório.

## Regras do Projeto
### Instruções do Docker
Sempre execute os containers locais usando `docker compose up -d`.

## Processos
### Deploy em Staging
Para realizar o deploy em staging, execute o script `npm run deploy:staging`.
