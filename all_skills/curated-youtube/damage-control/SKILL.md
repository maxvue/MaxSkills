# Skill: damage-control

## 📖 Visão Geral (Overview)

### Português (pt-BR)
Atua como um escudo de segurança impedindo que agentes autônomos excluam acidentalmente dados de produção ou executem operações perigosas.

**Descrição Detalhada:**
Mecanismo de proteção contra operações destrutivas e isolamento em sandboxes.

### English
Acts as a safety shield preventing autonomous agents from accidentally deleting production data or running dangerous operations.

**Detailed Description:**
High-risk command interceptor and sandbox guardrail preventing accidental data loss, destructive SQL, and uncommitted git wipes.

1. **Investigação Prévia:** Analise o contexto e os arquivos antes de aplicar alterações.
2. **Isolamento Seguro:** Realize testes e modificações com isolamento de ambiente (worktrees ou sandboxes).
3. **Validação Contínua:** Execute suítes de testes automatizados e verifique integridade após cada etapa.
4. **Documentação Integrada:** Mantenha registros claros das decisões e passos executados.
